## 1. Domain Entities & Enums

### A. `ConditioningMode` (Enum)
Defines how video diffusion models anchor visual motion for a specific beat:
```python
class ConditioningMode(str, Enum):
    PURE_T2V = "pure_t2v"                       # Freeform motion from text prompt only
    START_FRAME_ONLY = "start_frame_only"       # Seeded from initial keyframe (Frame 0)
    START_AND_END_FRAME = "start_and_end_frame" # Interpolation between Frame 0 and Frame N
    CHAIN_FROM_PREVIOUS = "chain_from_previous" # Frame 0 = Last frame of prior beat
    HARD_CUT = "hard_cut"                      # Explicit fresh keyframe with no chaining
```

### B. `ApprovalStatus` (Enum)
Tracks the human-in-the-loop review state:
```python
class ApprovalStatus(str, Enum):
    PENDING_REVIEW = "pending_review"                   # Initial draft generated, awaiting user review
    MODIFICATIONS_REQUESTED = "modifications_requested" # User requested delta changes
    APPROVED = "approved"                               # Locked and ready for master video rendering
    REJECTED = "rejected"                               # Session discarded
```

### C. `SceneBeatPlan` (Entity)
Represents a single planned visual and auditory scene in the storyboard:
- `beat_index` (int): 1-indexed order.
- `name` (str): Narrative title (e.g., *"The Red Expanse"*).
- `duration_sec` (float): Duration in seconds (e.g., 3.5).
- `conditioning_mode` (ConditioningMode): Determined framing strategy.
- `camera_movement` (str): Camera motion directive (e.g., *"slow_push_in"*, *"tracking_right"*, *"macro_tilt"*).
- `visual_prompt` (str): Descriptive 8K cinematic prompt used for visual synthesis.
- `keyframe_image_path` (Optional[str]): Local file path to the generated or provided 9:16 visual plate.
- `start_frame_path` (Optional[str]): Explicit Frame 0 path if applicable.
- `end_frame_path` (Optional[str]): Explicit Frame N path if applicable.
- `character_references` (List[str]): Identifiers of bound characters (e.g., `["astronaut_sarah"]`).
- `environment_reference` (Optional[str]): Identifier of bound environment concept.
- `dialogue_text` (Optional[str]): Spoken narration line. If null or empty, voiceover is silent for this beat.
- `sound_effects` (List[AudioCuePlan]): Contextual SFX with offset seconds and volume.

### D. `DirectorMasterPlan` (Entity)
The complete production plan generated by the autonomous director:
- `title` (str): Project title.
- `genre` (Genre): Story genre (`cinematic_story`, `riddle`, `action`, `documentary`).
- `target_aspect_ratio` (str): Default `"9:16"`.
- `total_duration_sec` (float): Sum of all beat durations.
- `voiceover_enabled` (bool): Global voiceover toggle.
- `voice_persona` (str): Neural voice identifier (e.g., `"en-US-ChristopherNeural"`, `"en-US-JennyNeural"`).
- `voice_speed` (float): Speed multiplier (0.8 to 1.3, default 1.0).
- `music_genre_and_mood` (str): Music sonic palette (e.g., `"ambient_space_drone"`, `"synthwave_chase"`).
- `music_base_volume` (float): Normal music volume (0.0 to 1.0).
- `music_ducked_volume` (float): Volume when narration is active.
- `subtitles_enabled` (bool): Global subtitle toggle.
- `subtitle_preset` (str): Styling preset (`"bold_yellow_glow"`, `"cinematic_minimal"`, `"none"`).
- `scenes` (List[SceneBeatPlan]): Sequence of planned beats.

### E. `StoryboardSession` (Aggregate Root)
Manages the active conversational pre-production state:
- `session_id` (str): UUID string.
- `created_at` (str): ISO timestamp.
- `updated_at` (str): ISO timestamp.
- `initial_prompt` (str): Raw input prompt or concept text.
- `reference_assets` (Dict[str, ReferenceAsset]): Map of tag ➔ ReferenceAsset (characters, environments).
- `plan` (DirectorMasterPlan): Current active production plan.
- `approval_status` (ApprovalStatus): Current review status.
- `history` (List[SessionTurn]): Record of conversational instructions and applied diffs.

### F. `SessionTurn` (Value Object)
- `turn_index` (int): Order of user-director interaction.
- `user_message` (str): Natural language instruction.
- `modified_beats` (List[int]): Indices of beats affected by this turn.
- `summary_of_changes` (str): System description of applied changes.
- `timestamp` (str): ISO timestamp.
