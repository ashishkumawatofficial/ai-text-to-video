## Summary

Build an interactive, high-performance Web Studio interface running locally on `localhost`. The studio consists of a Python FastAPI backend (`core/server.py`) exposing REST & Server-Sent Events, and a decoupled modern React 18 + Vite frontend (`studio/`) embedding `@remotion/player`. The interface provides a 3-panel creative workstation: (1) Directing & Gemini AI Copilot Chat sidebar for conversational script/beat editing, (2) Visual Canvas displaying interactive narrative beat cards with keyframe previews, single-beat re-rolls, and aspect ratio controls (`9:16` vs `16:9`), and (3) Live in-browser 60 FPS Remotion video player accompanied by a real-time RunPod Serverless GPU worker telemetry grid and live USD billing calculation.

---

## Technical Context

**Language/Version**: Python 3.12 (Backend) + TypeScript / React 18 (Frontend)  
**Primary Dependencies**: 
- Backend: `fastapi`, `uvicorn`, `pydantic`, `google-genai`, `requests`
- Frontend: `vite`, `react`, `react-dom`, `@remotion/player`, `lucide-react`, `tailwindcss`  
**Storage**: Ephemeral in-memory studio session state, local filesystem artifacts under `outputs/` and `cache/keyframes/`  
**Testing**: `pytest` (API and contract tests), Playwright/Cypress or component test for React studio  
**Target Platform**: Localhost (`http://localhost:5173` frontend, `http://localhost:8000` backend) on macOS / Linux / Windows  
**Project Type**: Full-stack web application (FastAPI backend + Vite SPA frontend)  
**Performance Goals**: Canvas rendering < 15s, conversational chat update < 8s, 60 FPS in-browser player scrubbing, parallel 4-beat serverless video synthesis < 3 min  
**Constraints**: Zero cloud storage fees ($0.00 idle), immediate cloud worker cancellation on abort, 100% backward compatibility with CLI commands  
**Scale/Scope**: Single-user local creative studio, up to 10 narrative beats per video project

## Constitution Check

- **I. Standalone Module**: The FastAPI server is completely isolated in `core/server.py`, reusing existing `InteractiveDirector`, `StoryWriter`, and `RunPodServerlessClient` without modifying their core logic. (`PASS`)
- **II. CLI Parity**: The web studio operates alongside the existing CLI commands (`python -m core.cli direct`). CLI functionality remains 100% intact. (`PASS`)
- **III. Resilient Failover**: Backend dispatch honors the tri-tier cascade (`SERVERLESS` ➔ `POD` ➔ `LOCAL`). (`PASS`)
- **IV. Wallet Protection**: UI exposes instant "Cancel All" triggering batch cloud cancellation. (`PASS`)
